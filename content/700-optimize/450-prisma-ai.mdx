## Prisma AI

Prisma AI helps you understand and refine query optimization recommendations through interactive dialogue.  

### Key Features  
- **Follow-up Questions**: Ask for clarifications on optimization suggestions.  
- **Automated Insights**: Get alternative solutions or deeper analysis.  
- **Learning Mode**: Request examples or step-by-step explanations.  

### Example  
**User**: *"Why does this recommendation suggest adding an index?"*  
**Prisma AI**: *"The query scans 10k rows without an index. Adding an index on `user_id` reduces scan time by ~90%."*
